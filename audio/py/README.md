# أصوات المقاطع الصينية (البينيين)

تسجيلات بشرية حقيقية لكل مقطع بنغماته الأربع، بعد قصّ الصمت بهامش، وتلاشٍ ناعم في الآخر، وتوحيد مستوى الصوت (بدون ضغط ديناميكي).
