🔤 Symbols and tone marks

What is the meaning of the signs above the letters? (click)
  • ā The first tone — a steady high level.
  • á The second - rising, as if you were asking.
  • ǎ The third - go down and then go up.
  • à The fourth - descending sharply.
  • a Unmarked — light, fast.
  • ü is not u: Purse your lips, then pronounce “ee.”

Numbering: 。 point · ， comma · ？ interrogative · ！ He marveled.

Pronunciation change: 不 is written bù But before a descending tone is pronounced bú, and一 You become yí in yíxià. The writing doesn't change — only the pronunciation.

Only once (3 minutes) 1) Open github.com/settings/personal-access-tokens/new and log in.
2) Token name: Write lessons, and Expiration: Select No expiration or a year.
3) Repository access: Select Only select repositories Then choose Your site's repository.
4) Permissions ← Repository permissions ← Contents: Choose Read and write.
5) Press Generate token, copy the code and paste it here.

The code remains on this device only and is used to upload the lessons to your site repository alone.
